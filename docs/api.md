# API 0.1

Все пути относительно `/api`. OpenAPI: `/docs` на backend, например
`http://127.0.0.1:8001/docs` в локальном профиле. Порт 8000 оставлен обычному сайту.
Для браузерного UI используется
один origin, `/api` проксируется Vite либо nginx.

| Запрос | Назначение | Доступ |
|---|---|---|
| GET `/health` | Проверка сервера и БД | Открыт |
| POST `/auth/login` | Логин/пароль, HttpOnly cookie, ответ csrf | Открыт, ограничение попыток |
| GET `/auth/me` | Текущий пользователь и csrf | Сессия |
| POST `/auth/logout` | Отзыв сессии | Сессия + CSRF |
| GET `/catalog` | Предприятия, цеха, агрегаты | Все роли |
| POST `/organizations`, `/workshops`, `/assets` | Создание структуры | Администратор / главный инженер |
| GET, POST `/motors` | Реестр / создание двигателя | Чтение всем; запись администратору / главному инженеру |
| GET, PUT `/motors/{id}` | Карточка / редактирование | Аналогично |
| POST `/motors/{id}/archive` | Архивирование / возврат | Администратор / главный инженер |
| GET `/motors/{id}/measurements?hours=1&limit=2000` | Сохранённые временные ряды | Все роли |
| POST `/motors/{id}/baseline` | Явное утверждение базы | Администратор / главный инженер |
| GET, POST `/devices` | Устройства / виртуальная регистрация | Чтение всем; запись администратору / главному инженеру |
| PUT `/devices/{id}/simulation` | Сценарий, включение, интервал | Администратор / главный инженер, только demo |
| GET `/simulator/devices` | Конфигурации виртуальных устройств | Отдельный `X-Gateway-Key` |
| POST `/ingestion` | Валидируемое идемпотентное сохранение | Отдельный `X-Gateway-Key` |
| GET `/stream` | SSE `update` каждые 2 с | Сессия |
| GET `/alerts`, `/alerts/{id}` | События, объяснения, история | Все роли |
| PATCH `/alerts/{id}` | Статус, исполнитель, комментарий | Инженер и выше |
| POST `/alerts/{id}/inspections` | Осмотр, подтверждение, выполненные работы | Инженер и выше |
| GET `/reports/measurements.csv?motor_id=...&hours=24` | CSV UTF-8 BOM для Excel | Все роли |
| GET `/settings` | Несекретные параметры сервера | Все роли |
| GET, POST `/users` | Пользователи / создание | Чтение администратору/главному инженеру; создание администратору |

Изменяющие запросы пользователя требуют `X-CSRF-Token` из `/auth/me`. Ключ
симулятора не даёт доступа к пользовательским API. Наблюдатель не может писать,
даже если вручную отправит запрос без интерфейса. Сессионный токен хранится только
как SHA-256, пароль — Argon2id. Пароли не записываются в аудит.

`hours`: 1–720. История графика ограничена последними 2000 точками по умолчанию,
максимум 10000. `truncated=true` явно сообщает об ограничении; агрегация не
подменяет фактические записи. CSV: максимум 100000 записей, иначе 422 с предложением
сократить период. Список событий — последние 500, не бесконечная пагинация.

В первом срезе все пользователи видят одну установленную систему; организация
служит структурным фильтром, не изоляцией арендаторов. Физические устройства
и перенос установок не регистрируются этим UI. Один backend worker обязателен
для текущего SQLite-профиля; многопроцессная эксплуатация требует отдельного этапа.
