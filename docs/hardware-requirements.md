# MEKORA Core · предварительные требования

Это описание для разработки и испытаний, **не производственная спецификация**,
не CAD-чертёж и не подтверждение промышленной пригодности.

Кандидаты: ST IIS3DWB (трёхосевой вибрационный MEMS, SPI), Nordic nRF52840
(вычисление признаков/BLE), PT1000 с отдельным прецизионным измерительным трактом
(температура контакта). Батарея выбирается по реальному профилю duty cycle,
потреблению записи и передачи. Автономность до измерений не обещается.

Сигнальная цепь: контакт двигателя → жёсткое основание → вибросенсор → SPI → MCU
→ пакет с версией, временем, последовательностью и качеством → BLE → Linux Gateway
→ буфер/HTTP → Monitor. Термоконтакт → PT1000 → токовый источник/АЦП → MCU.
Положение осей должно быть задано монтажной инструкцией.

Концепт корпуса: графитовый радиопрозрачный верх с логотипом MEKORA и небольшим
индикатором, внутри батарея/плата/антенна, металлическое основание с тепловым
контактом, съёмное жёсткое соединение с Mount Flat, промышленный конструкционный
клей, подготовленная поверхность двигателя. Mount Fin — последующая адаптация
для рёбер. Ранее предложенные 65×45×22 мм — только дизайнерская гипотеза.

План проверки до фиксации конструкции:

1. Частотная характеристика корпуса, клеевого слоя и адаптера на вибростенде;
   сравнение с опорным датчиком, влияние повторного монтажа и ориентации.
2. Частотная полоса, динамический диапазон, шум, клиппирование, АЦП, anti-aliasing,
   сравнение RMS/FFT и скорости с эталоном и тестовыми сигналами.
3. Температурная инерция и погрешность контакта, нагрев электроники/батареи,
   климатические испытания; допустимые температуры по выбранным компонентам.
4. Измеренный ток сна, записи, вычислений и BLE; батарея при холоде/нагреве,
   замена и ремонт, потери энергии при повторных передачах.
5. Радиоканал рядом с металлическим корпусом и в цехе, антенна/зазоры,
   потери пакетов, временная синхронизация и буфер шлюза.
6. Герметизация, пыль/влага, химическая стойкость, EMC, механические удары,
   маркировка и подтверждение требований испытаниями. IP-рейтинг пока не присвоен.

Перед передачей конструктору нужны выбранные габариты батареи/платы, тепловой
стек, монтажные допуски, площадь клея, способ снятия и доступа к батарее,
антенный keep-out, масса, допустимые резонансы и критерии приёмки. Физические
устройства в программном прототипе не испытаны.
